# Gulf CV (UAE & KSA)

Gulf CVs are screened on eligibility fields (visa status, nationality, location, notice period) before the experience is read. Build every CV so those fields, plus job title, current role, employer and total years of experience, are visible in the top third of page one.

## Before writing
Collect (ask only for what's missing): target role(s) and country (UAE, KSA or both), current location, nationality, visa/Iqama status, notice period or availability date, driving licence, languages (incl. any Arabic), degree attestation status, the job posting if there is one, and the existing CV/LinkedIn. Never invent facts, numbers, dates or credentials; flag gaps as questions.

## Always produce two versions
| Version | Photo | DOB / marital status | Use for |
|---|---|---|---|
| A: ATS | No | No | Company career portals, multinationals, tech firms, Workday-type systems (e.g. STC, PIF, NEOM, Red Sea Global) |
| B: Direct | Professional, conservative headshot placeholder | Yes | Emailing recruiters, agencies, Bayt, Naukrigulf, traditional employers (e.g. Aramco, SABIC, Maaden-style systems that expect photo, DOB, full academic history) |

Never include religion, passport number or full home address in either.

## Header block (plain text, never in a sidebar, text box, header or footer)
- Full name + target job title matching the posting
- Phone with country code, marked WhatsApp
- Professional email, LinkedIn URL
- Current location, e.g. "[City, Country], available to relocate from [date]"
- Nationality: one line
- Visa status, specific (e.g. Employment Visa, Visit Visa, Dependent visa, Transferable Iqama, GCC national; if abroad: "requires sponsorship, available from [date]")
- Notice period / availability
- Driving licence if relevant
- Languages, including any Arabic level

## Structure and format
- 2 pages standard (3 only for senior); never a one-page US-style resume
- Order: Header, Professional Summary, Core Skills, Work Experience (reverse-chronological), Projects, Education, Certifications, Languages, References (optional)
- Single column, plain text, standard section headings; no tables, columns, icons, graphics or Canva-style templates
- Clean font (e.g. Arial/Calibri 10-12pt); export PDF; file name FirstName_LastName_CV_YYYY.pdf

## Content rules
- Summary: 3-4 factual lines starting with role + years + domain. No vague objectives ("seeking a challenging opportunity...") and no inflated branding language.
- Bullets are achievements with numbers, not duties.
- Mirror the posting's exact job title and skill keywords (Bayt/GulfTalent/Naukrigulf recruiters search by keyword).
- Spell credentials in full with acronym: "Project Management Professional (PMP)"; note issuer and year.
- Highlight Gulf/regional experience with company, city and dates.
- Keep CV and LinkedIn consistent.
- References: "Available upon request" unless the job asks. Salary: leave off.

## UAE specifics
- Visa status and availability are the first filter ("in UAE" vs "needs sponsorship").
- Degree attestation: home country first, then UAE MOFA. Add a line "Degree attestation: completed / in progress" under Education.
- Portals: Bayt, GulfTalent, Naukrigulf, LinkedIn.

## KSA specifics
- Name a Vision 2030 theme the work touched (digital transformation, healthcare, sustainability, financial services, tourism) in the summary. Tech/data roles are in demand.
- Use conventional job titles that map to the Saudi Standard Classification of Occupations (SSCO), since employers draft contracts in Qiwa. No creative titles.
- List Saudi Professional Accreditation if held (programme covers Bangladesh, India, Pakistan, Sri Lanka, Egypt).
- If in KSA, state whether the Iqama is transferable.
- Saudization reserves many roles for nationals; frame specialised skills that justify an expat hire.

## Final check before delivering
- Filter fields visible in top third of page 1 in plain text
- Both versions produced, correct personal-detail rules for each
- Keywords and title match the posting
- Every bullet quantified or concrete; nothing invented
- 2 pages, single column, ATS-safe
- List any open questions (missing dates, numbers, visa details) for the user
